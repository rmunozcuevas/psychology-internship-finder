# Location coverage

The catalogue total spans all collected source locations, including small cities, suburbs, multiple-site labels, remote regions, international sites and listings without a location. A featured-city count is a subset, not a share evenly allocated from the total.

The location browser groups every active record once under its complete employer-provided location. Its internship totals therefore reconcile exactly to the internship catalogue. Multi-location records remain one record in this browser. City/metro searches can overlap, so summing those cards is not a catalogue total.

Metro search is enabled by default and can be changed to strict city-only search. Sixteen configured nearby-place groups cover the major search regions; cities without a configured group stay city-only. The UI exposes every included place. These are curated search groups, not official statistical boundaries or commute-radius guarantees. Employers' worksite labels remain visible.

Regional reference sources include [Sound Transit's service map](https://www.soundtransit.org/sites/default/files/documents/st-current-service-map.pdf), the [Charlotte region map](https://webservices.ncleg.gov/ViewDocSiteFile/66175), and [MTC's description of the Bay Area](https://www.mtc.ca.gov/about-mtc/what-mtc). No transit availability or commute time is inferred for an internship.

A city-only query matches source location rather than an incidental headquarters mention in the description. ATS formats such as state-first labels, workplace prefixes and street addresses are normalized conservatively. Known foreign country labels do not get reassigned to a similarly named U.S. city. Missing or ambiguous geography is not a verified worksite.

Path49 does not promise a minimum number in any particular city. More search coverage makes existing postings discoverable; additional employer sources are needed where the underlying feed is thin.
