# Help build the internship directory

Fieldnote is a free public directory for psychology students, including UNCC students. Anyone can browse it without an account. Contributions make the employer source list and verified Summer 2027 program list more useful.

## Good first contributions

- Suggest an official employer or university careers page with a psychology, behavioral health, neuroscience, community, or people research internship.
- Check a program link and report a changed deadline, date, or eligibility requirement.
- Improve a filter, keyboard interaction, mobile layout, or plain language label.
- Add a board identifier to `employer-boards.json` after verifying the employer links to that public board.

Suggested starter tasks: verify whether an official 2027 program has opened; add one verified university or nonprofit careers board; improve the mobile search labels; or add an accessible message for an empty filter result. Search the open Issues page for work that already has a discussion before starting.

## Source guidelines

Use employer, university, nonprofit, or program pages as the source of truth. Do not add copied job descriptions from LinkedIn or Indeed. Link to the original posting and describe uncertain dates as uncertain. Do not include personal information in issues or pull requests.

## Make a change

Open an issue using the “Suggest an employer board” or “Report a listing” form, or submit a pull request. Include the official source URL and evidence that the board is operated by the employer. Keep changes small and easy to review.
